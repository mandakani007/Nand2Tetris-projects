# Part B – Hack Assembler

This section contains the Python implementation of a two-pass Hack Assembler.

## Files
- Assembler.py
- Add.asm
- Max.asm
- Rect.asm
- Pong.asm
- symbols.txt

## Functionality
- Removes comments and blank lines.
- Identifies labels in the first pass.
- Converts instructions into 16-bit binary in the second pass.
- Allocates variables from RAM address 16.
- Saves labels and variables with their addresses in symbols.txt.
