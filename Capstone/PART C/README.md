# Part C – Box Drawing Program

This section contains the Hack Assembly program that draws a black box on the screen while a key is pressed and erases it when the key is released.

## Files
- Box.asm – Hack Assembly source code.
- Box.hack – Machine code generated using our own Python assembler.

## Box Specifications
- K = 54
- Starting row = 54
- Height = 20 rows
- Width = 48 pixels
- Starting screen address = 18112

## Execution
Box.asm was converted into Box.hack using the custom assembler developed in Part B. The generated machine code was executed in the Nand2Tetris CPU Emulator.
